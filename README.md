# Amazon.com.br – Clone (Figma Turbo)
Implementação do projeto **PROJETO AMAZON** (Home, Menu aberto, Login e Produto) em HTML5, CSS3 e JavaScript.
Páginas: `index.html` (menu lateral pelo botão ☰ Todos), `login.html`, `produto.html`.

## Publicar no GitHub Pages
1. Crie um repositório público e envie estes arquivos na raiz (`git init && git add . && git commit -m "projeto amazon" && git push`).
2. No repositório: **Settings → Pages → Deploy from a branch → main / (root) → Save**.
3. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
